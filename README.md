## 📝 Conventional Commit Guidelines

This project strictly enforces the [Conventional Commits](https://www.conventionalcommits.org/) standard:
- `chore:` Initial repository setup, licensing, and file initialization.
- `docs:` Documentation additions and improvements (`README.md`, `CLAUDE.md`).
- `feat:` Feature implementations.
- `fix:` Bug fixes.
